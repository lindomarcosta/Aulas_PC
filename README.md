# Aulas_PC
Aulas de programação para iniciantes

Bem-vindo ao curso de programação do zero! Este repositório contém aulas passo a passo para quem está começando na área de desenvolvimento web.

## 📚 Sumário do Curso

| Aula | Tema | Descrição |
|------|------|-----------|
| [Aula 01](./aula_01_html/) | HTML | Estrutura e elementos básicos de uma página web |
| [Aula 02](./aula_02_css/) | CSS | Estilização e layout de páginas web |
| [Aula 03](./aula_03_javascript/) | JavaScript | Programação e interatividade na web |
| [Aula 04](./aula_04_github_copilot/) | GitHub Copilot | Assistente de IA para programação |

## 🚀 Como usar este repositório

1. Clone o repositório: `git clone https://github.com/lindomarcosta/Aulas_PC.git`
2. Acesse a pasta da aula desejada
3. Leia o arquivo `README.md` de cada aula
4. Pratique com os arquivos de exemplo

## 📋 Pré-requisitos

- Um computador com acesso à internet
- Um editor de texto (recomendamos o [Visual Studio Code](https://code.visualstudio.com/))
- Um navegador web (Chrome, Firefox, Edge, etc.)

## 🎯 Objetivo

Ao final do curso, você será capaz de:
- Criar páginas web com HTML
- Estilizar páginas com CSS
- Adicionar interatividade com JavaScript
- Usar o GitHub Copilot para acelerar seu desenvolvimento

🌐 O que é HTML? (10 min)

HTML (HyperText Markup Language) é a linguagem de marcação que estrutura o conteúdo das páginas web. Ele não é uma linguagem de programação — ele descreve o que cada coisa é: título, parágrafo, imagem, link.

Analogia: HTML é como o esqueleto do site. CSS é a roupa e JavaScript é o movimento.

O que vamos construir?

  • Um cabeçalho com nome e profissão
  • Um menu de navegação funcional
  • Seção "Sobre Mim" com foto e biografia
  • Lista de habilidades
  • Formulário de contato
  • Rodapé

🛠 Ferramentas Necessárias (5 min)

  • VS Code — Editor de código (gratuito) → code.visualstudio.com
  • Extensão Live Server — Recarrega o navegador automaticamente ao salvar o arquivo
  • Navegador — Chrome, Edge ou Firefox
Como instalar Live Server: No VS Code, clique no ícone de extensões (Ctrl+Shift+X), pesquise "Live Server" e instale.

📖 Teoria: Estrutura Base HTML (20 min)

Todo arquivo HTML começa com uma estrutura padrão. Crie um arquivo chamado index.html e observe cada parte:

<!-- Estrutura Base HTML -->
<!DOCTYPE html>
<html lang="pt-br">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Meu Portfólio</title>
  <link rel="stylesheet" href="styles.css">
</head>
<body>

  <!-- Todo o conteúdo visível vai aqui -->

</body>
</html>

🔍 Explicando cada tag

<!DOCTYPE html> Avisa ao navegador que este é um documento HTML5 moderno. <html lang="pt-br"> Raiz de todo o documento. O atributo lang define o idioma (ajuda no SEO e acessibilidade). <head> Configurações da página que não aparecem para o usuário (metadados, links de CSS). <meta charset> Permite usar acentos e caracteres especiais (ç, ã, é). <meta viewport> Garante que o site funcione bem em celulares (responsividade). <title> Texto que aparece na aba do navegador. <link> Conecta o HTML ao arquivo de estilos CSS. <body> Corpo da página. Tudo que o usuário vê (textos, imagens, botões) fica aqui.
Regra de ouro: Toda tag que abre deve ser fechada: <h1>...</h1>. Exceções: <meta>, <link>, <img>, <input>.

🖊 Prática — Criar index.html (15 min)

  1. Abra o VS Code e crie uma pasta chamada meu-portfolio.
  2. Crie um arquivo index.html dentro da pasta.
  3. Digite ! e pressione Tab para gerar a estrutura automaticamente (atalho Emmet).
  4. Altere o lang para "pt-br" e o <title> para "Meu Portfólio".
  5. Dentro do <body>, adicione: <h1>Olá, mundo!</h1>
  6. Salve (Ctrl+S) e clique em "Go Live" (canto inferior direito do VS Code).
  7. Veja o resultado no navegador! 🎉
Dica: Sempre que salvar o arquivo, o Live Server atualiza o navegador automaticamente.

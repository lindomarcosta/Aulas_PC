📖 Teoria: Cabeçalho e Menu (15 min)

Adicione o código abaixo dentro do <body> do seu arquivo:

<header>
  <h1>Olá, eu sou João Silva! 👋</h1>
  <p>Desenvolvedor Web em formação</p>
</header>

<nav>
  <ul>
    <li><a href="#sobre">Sobre Mim</a></li>
    <li><a href="#habilidades">Habilidades</a></li>
    <li><a href="#contato">Contato</a></li>
  </ul>
</nav>

🔍 Explicando cada tag

TagO que faz
<header>Define o cabeçalho introdutório da página.
<h1>Título principal (Heading 1). Deve haver apenas um por página.
<nav>Define uma seção de navegação.
<ul>Lista não ordenada (Unordered List) — gera bolinhas.
<li>Item de lista (List Item).
<a href="...">Cria um link. O #sobre é uma âncora: rola a página até o elemento com id="sobre".
Link interno vs externo:
href="#sobre" → rola para a seção na mesma página.
href="https://site.com" → abre outro site.

🖊 Prática: Adicionar Cabeçalho e Menu (10 min)

  1. Abra o arquivo index.html no Replit (painel esquerdo, clique no arquivo).
  2. Dentro do <body>, cole o código de <header> e <nav> acima.
  3. Substitua "João Silva" pelo seu nome.
  4. Salve e veja no navegador — os itens de menu devem aparecer como links clicáveis.
Resultado esperado: Título com seu nome e três links de menu. Ainda sem estilo (feio é normal — o CSS vem na Aula 4!).

📖 Teoria: Seção "Sobre Mim" (10 min)

Adicione o código abaixo após o </nav>:

<section id="sobre">
  <h2>Sobre Mim</h2>

  <!-- Use uma foto sua ou deixe este placeholder por enquanto -->
  <img
    src="https://via.placeholder.com/150"
    alt="Foto de João Silva"
    width="150"
  >

  <p>
    Olá! Me chamo João, tenho 25 anos e estou aprendendo
    desenvolvimento web. Adoro resolver problemas e criar
    interfaces que fazem sentido para as pessoas.
  </p>
</section>

🔍 Explicando cada tag

Tag / AtributoO que faz
<section id="sobre">Divide o conteúdo em blocos temáticos. O id é o alvo do link #sobre do menu.
<h2>Subtítulo da seção (Heading 2).
<img src="...">Exibe uma imagem. src é o caminho do arquivo.
alt="..."Texto alternativo para acessibilidade e quando a imagem não carrega. Sempre use!
Foto real: Para usar sua foto, coloque o arquivo (ex: foto.jpg) na mesma pasta do index.html e mude o src para src="foto.jpg".

🖊 Prática: Criar Seção "Sobre Mim" (10 min)

  1. Após o </nav>, adicione a <section id="sobre">.
  2. Escreva sua própria bio no parágrafo.
  3. Se quiser, adicione sua foto colocando o arquivo na pasta e apontando o src.
  4. Salve e teste o link "Sobre Mim" do menu — a página deve rolar até essa seção!

📖 Teoria: Seção de Habilidades (10 min)

Adicione após o </section> do "Sobre Mim":

<section id="habilidades">
  <h2>Minhas Habilidades</h2>
  <ul>
    <li>🌐 HTML — Iniciante</li>
    <li>🎨 CSS — Iniciante</li>
    <li>💻 Lógica de Programação — Estudando</li>
    <li>🗣 Inglês — Intermediário</li>
  </ul>
</section>
Dica: Seja honesto com o nível das suas habilidades. Recrutadores valorizam a honestidade mais do que a superestimação.

📖 Teoria: Formulário de Contato (15 min)

Adicione após a seção de habilidades:

<section id="contato">
  <h2>Entre em Contato</h2>

  <form action="#">

    <label for="nome">Nome:</label>
    <input type="text"
           id="nome"
           name="nome"
           placeholder="Seu nome aqui">

    <label for="email">E-mail:</label>
    <input type="email"
           id="email"
           name="email"
           placeholder="seu@email.com">

    <label for="mensagem">Mensagem:</label>
    <textarea id="mensagem"
              name="mensagem"
              rows="4"
              placeholder="Escreva sua mensagem..."></textarea>

    <button type="submit">Enviar Mensagem</button>

  </form>
</section>

🔍 Explicando as tags do formulário

Tag / AtributoO que faz
<form action="#">Container do formulário. action define para onde enviar os dados (usamos # por enquanto).
<label for="...">Rótulo do campo. O for deve ser igual ao id do input — melhora a acessibilidade.
<input type="text">Campo de entrada de texto curto.
<input type="email">Campo de e-mail — valida automaticamente o formato.
placeholder="..."Texto de dica que some quando o usuário digita.
<textarea rows="4">Campo de texto grande. rows define a altura inicial.
<button type="submit">Botão para enviar o formulário.
Por que for e id devem ser iguais? Isso faz com que ao clicar no label (ex: "Nome:"), o cursor salte direto para o campo. Fundamental para acessibilidade!

📖 Teoria: Rodapé (5 min)

Adicione após a última </section>, antes do </body>:

<footer>
  <p>© 2026 João Silva — Todos os direitos reservados</p>
</footer>
Boa prática: O <footer> fica sempre fora das seções, no final do <body>. Coloque informações de copyright, links de redes sociais ou créditos.

🖊 Revisão: HTML Completo (10 min)

Ao final da Aula 3, seu arquivo deve ter esta estrutura:

<body>
  <header> ... </header>
  <nav> ... </nav>
  <section id="sobre"> ... </section>
  <section id="habilidades"> ... </section>
  <section id="contato"> ... </section>
  <footer> ... </footer>
</body>
  • Teste todos os links do menu — cada um deve rolar até a seção correta.
  • Clique no label "Nome:" — o cursor deve ir para o campo.
  • Tente enviar um e-mail inválido — o navegador deve reclamar.

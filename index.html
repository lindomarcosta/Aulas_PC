🖥️ Página de Apresentação Pessoal em HTML

Plano de Aulas — Desenvolvimento Web para Iniciantes

⏱ 4 Aulas · 50 minutos cada · Nível: Iniciante

📋 Visão Geral do Curso

Neste curso prático você vai criar do zero uma Página de Apresentação Pessoal (Portfólio) usando HTML e CSS. Ao final das 4 aulas você terá um site real com cabeçalho, menu de navegação, seção "Sobre Mim", lista de habilidades, formulário de contato e rodapé — tudo estilizado com CSS.


  • ✅ Pré-requisito: Nenhum — basta ter VS Code e um navegador instalados.
  • ✅ Material: Guia em PDF + exemplos de código em cada aula.
  • ✅ Resultado final: Portfólio publicável online.
